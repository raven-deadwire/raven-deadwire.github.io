OBS 필터만 설치

위 설치 파일에는 OBS Studio 필터가 선택 설치 항목으로 이미 들어 있습니다(Windows는 Windows 설치기에 포함). 필터만 추가하려면 아래 패키지를 받아 OBS를 종료한 뒤 압축을 푼 폴더에서 ./install.sh를 실행하세요. Chimera VST3가 설치되어 있어야 합니다.

macOS용 OBS 필터 (Universal, macOS 12 이상)chimera-obs-macos-universal-5bbc2715df.zipLinux x86_64용 OBS 필터chimera-obs-linux-x86_64-5bbc2715df.tar.gz

Linux는 배포판 패키지로 설치한 OBS(Flatpak·Snap 미지원)와 glibc 2.38 이상이 필요하고, 에디터 창은 X11(Wayland에서는 XWayland)이 필요합니다. macOS 모듈은 아직 Apple 공증 전입니다. 이 패키지는 1.4.1-beta.1과 함께 공개된 것이며, OBS 필터 코드는 1.5.0-beta.1에서도 같습니다. 체크섬

라이선스 유효기간

이 베타는 2027-05-31 23:59 KST(2027-05-31 14:59 UTC)까지 사용할 수 있습니다. SETTINGS에 남은 시간이 표시되고, 14일 전부터 경고합니다.

이미 열려 있는 인스턴스는 만료 후에도 계속 동작합니다. 만료 후 새로 연 인스턴스는 설정을 보존한 채 출력이 꺼집니다.

인증된 베타테스터 코드(SETTINGS → Enter beta tester code...)를 입력하면 그 컴퓨터에서 만료가 무기한 해제됩니다.

1.5의 새 기능

  • POST 두 번째 슬롯: POST 섹션마다 독립된 두 번째 슬롯이 생깁니다(예: 딜레이 두 개 동시 사용). 두 번째 슬롯은 모두 꺼진 채 시작하며 기존 프로젝트의 소리는 같습니다.
  • POST 페이지에서 끌어서 순서 바꾸기: 랙 줄의 그립을 끌어 순서를 바꿉니다.
  • Metro Clean이 2채널 베이스 앰프가 됩니다(MODERN·CLASSIC, O/D SYMMETRY 추가). 저장한 프로젝트는 노브 값을 유지한 채 MODERN으로 열리지만, 기존 VOICING과 HI MID는 없어지고 HIGH PASS와 미드 주파수의 범위가 바뀌어 Metro Clean을 쓰는 프로젝트는 소리가 달라질 수 있습니다.
  • 레퍼런스 헤드 5종의 새 외관.
  • Auto Set 단계 8개 추가(모두 기본 꺼짐): Dual 두 리그와 Matrix MID·HIGH 레인의 앰프 설정.
  • 새 기능은 자동 시험만 거쳤습니다.

1.4.1의 새 기능

  • Auto Set 단계 7개 추가(모두 기본 꺼짐): 룸 앰비언스(Room Core), Dual 리그·Matrix 레인의 캐비닛 컷, 팩토리 IR 선택, 마이크 배치, 마이크 정렬·블렌드, Dual Blend의 부스트 페달. 합성 신호로만 확인했습니다.
  • OBS 필터가 OBS의 필터 저장 중에 넣은 프리셋을 유지합니다.
  • 모델·파라미터·저장한 프로젝트는 1.4.0-beta.1과 같습니다.

1.4의 새 기능

  • 선택 가능 모델 132종: AMP 30, PRE 51, POST 39, CREATIVE 9, SYNTH 3.
  • PRE 보드와 ROUTING 그래프에서 끌어서 바꾸는 신호 순서 편집.
  • 연주를 따라가는 SYNTH 페이지: 엔진 3종, 오실레이터 3개, 샘플 모드, 모드 매트릭스.
  • Room 공간 단계, 6밴드 다이내믹스, LUFS 미터를 갖춘 Studio true-peak 리미터.
  • Graphical EQ 그룹 편집, 밴드 SOLO, EQ별 A/B.
  • Auto Set 새 단계: 레인 극성, 딜레이 동기화, 팩토리 IR 선택, 악기 판별.
  • Easy view, A/B MATCH, 3개 OS의 OBS 필터.

스크린샷

1.4.0-beta.1 소스에서 캡처(Linux, 100%).

알려진 한계

  • 안정판이 아닌 베타입니다. Windows·macOS·Linux 자동 빌드와 시험은 통과했고, 실행하지 않은 엄격 검사 107개를 공개합니다.
  • 실제 기타·베이스 DI 청음과 실제 DAW·오디오 장치 수용은 아직입니다.
  • 설치기는 아직 공개 서명·공증되지 않았습니다. AAX는 포함되지 않습니다.
  • 기존 프로젝트는 소리를 유지합니다. 단, Metro Clean을 쓰는 프로젝트는 달라질 수 있습니다(1.5의 새 기능 참고). 새 파라미터는 뒤에 추가되고 꺼진 상태로 시작합니다.
